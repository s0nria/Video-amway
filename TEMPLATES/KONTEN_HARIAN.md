# KONTEN HARIAN 3–5 SEHARI — Momyizz (Amway)

Sumber idea: kalendar dan 10 episod dalam worksheet (`momyizz-planner.html`). Setiap episod dipecah kepada beberapa konten.
Penulisan ikut `PENULISAN_PLATFORM.md`. Video ikut `MASTER_WORKFLOW.md`.

## Agihan sehari — DISAHKAN (pilihan A)
Satu topik sehari. Setiap konten membincangkan perkara yang sama, tetapi **isi berbeza**.

| Masa | Konten | Platform | Salin ke |
|---|---|---|---|
| 08:30 | 🎥 **Untuk VIDEO** (45 s): cerita / personal branding | TikTok · Reels | CapCut / Flow |
| 12:30 | 🖼️ **Untuk CAROUSEL** (6 slaid): edukasi langkah demi langkah | Instagram · Facebook | Canva / CapCut |
| 10:00 | ✍️ **Teks sahaja**: info ringkas edukasi | Threads · Facebook | Post terus |
| 16:00 | ✍️ **Teks sahaja**: pertanyaan / poll | Threads · Facebook | Post terus |
| 18:30 | ✍️ **Teks sahaja**: tips praktikal (berbeza daripada isi video & carousel) | Threads · Facebook | Post terus |
| 21:00 | ✍️ **Teks sahaja**: info penting / alert (sumber rasmi: KKM, WHO, NHMS) | Threads · Facebook | Post terus |
| Bila sesuai | 💬 **Hard-sell** | WhatsApp / group tertutup | Hantar terus |

- Produk tidak muncul dalam video, carousel atau teks awam (peraturan Amway Malaysia). Produk, harga dan cara order hanya dalam WhatsApp / group tertutup.
- Hard-sell maksimum 1 sehari, 3–4 hari seminggu.
- Info "semasa" mesti dari sumber rasmi. Jangan reka berita.

## Template setiap slot

**Personal branding**
```
Situasi sebenar Momyizz hari ini → apa yang Momyizz rasa / belajar → soalan kepada korang
```

**Edukasi + soft-sell**
```
Hook → cerita ringkas → 1–3 fakta (label bukti + sumber) → amalan praktikal → produk sebagai pilihan (jika berkaitan) → CTA interaksi
```

**Interaksi**
```
Satu soalan / poll yang mudah dijawab, berkaitan topik episod
```

**Hard-sell** — ikut "Formula hard-sell" dalam `PENULISAN_PLATFORM.md`.

**Testimoni**
```
Situasi pelanggan → pengalaman mereka (kata-kata sendiri, tanpa dakwaan perubatan) → "Pengalaman individu mungkin berbeza" → CTA
```
