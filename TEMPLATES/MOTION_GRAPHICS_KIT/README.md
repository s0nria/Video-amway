# MOTION GRAPHICS KIT — Video Amway (Momyizz)

Komponen grafik standard untuk video 1080 × 1920. Semua komponen guna palet dan font dari `AMWAY_BRAND/BRAND.md` sahaja.

| Fail | Isi |
|---|---|
| `KOMPONEN.md` | Spesifikasi setiap komponen: saiz, warna, font, kedudukan, gerakan, bila guna |
| `tokens.css` | Token warna, font dan safe zone (untuk preview HTML atau rujukan Canva/CapCut) |
| `preview.html` | Paparan semua komponen di atas kanvas 9:16 dengan garis safe zone |

Cara guna:
1. Dalam skrip, tulis nama komponen (contoh `KAD_FAKTA`) di lajur Grafik.
2. Masa edit, bina komponen ikut `KOMPONEN.md`. Buka `preview.html` sebagai rujukan rupa.
3. Bila komponen siap dibina sebagai template dalam alat edit (Canva/CapCut), catat pautan/nama template dalam jadual "Template alat edit" dalam `KOMPONEN.md`.

Nilai saiz dan gerakan ialah **CADANGAN** sehingga pengguna sahkan.
